# Emergency Communication System using LoRa

**Technologies:** Embedded C, ESP32, LoRa, GSM, GPS, OLED

## Overview

An embedded communication project exploring message exchange and location sharing when conventional communication infrastructure is unavailable or unreliable.

## Project scope

- ESP32-based embedded system
- LoRa packet transmission
- GSM connectivity
- GPS-based location tracking
- OLED display integration

## Technical concepts demonstrated

- Embedded C development
- Microcontroller interfacing
- Wireless communication concepts
- Integration of communication and location modules
