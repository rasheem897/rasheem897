# Employee Management System

**Technologies:** Java, MySQL, JDBC, Object-Oriented Programming

## Overview

A Java application for managing employee records with relational database connectivity.

## Project scope

- Create, read, update and delete employee records
- Connect Java application logic to MySQL using JDBC
- Apply object-oriented programming concepts
- Include input validation and exception handling

## Technical concepts demonstrated

- Java classes and object-oriented design
- JDBC database connectivity
- SQL-based data operations
- Basic application-level validation and error handling
